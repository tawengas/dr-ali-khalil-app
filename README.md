# 🏥 عيادات النخبة الطبية

تطبيق موبايل (PWA) لإدارة عيادتين طبيتين — حجز مواعيد + إدارة كاملة.

## 👥 المستخدمون

- 👤 **المريض** — حجز بدون تسجيل
- 🩺 **الطبيب** — إدارة مواعيد عيادته
- 👑 **الأدمن** — إدارة كاملة

## 🏥 العيادات

| العيادة | الطبيب | التخصص |
|---------|--------|--------|
| عيادة د. علي خليل | د. علي خليل | جراحة |
| عيادة د. سالم شوبير | د. سالم شوبير | أسنان |

## 🔧 التقنيات

- **Frontend:** HTML + CSS + JavaScript (PWA)
- **Backend:** Cloudflare Workers
- **Database:** Cloudflare D1
- **Hosting:** Cloudflare Pages

## 🔗 روابط

- **API:** https://medical-app-api.gomanji-00.workers.dev
